**إضافة الصور الأربع**

القسم الجديد موجود بعد الأثر وقبل الانضمام. يحتوي على صورة كبيرة للتجمع السنوي وثلاث صور عادية. لم تُرفق صور فعلية في الطلب، لذلك تظهر أماكن مخصصة لها دون صور وهمية أو روابط مكسورة.

1. ضع الصور داخل مجلد `assets/gallery`.
2. افتح `assets/gallery-config.js`.
3. استبدل القيم الفارغة في `src` بمسارات صورك، مثل المثال التالي. اكتب امتداد الملف الحقيقي؛ يمكن استخدام JPG أو WebP أو PNG.
4. عدّل وصف `alt` ليصف الصورة الفعلية، ثم ارفع الصور وملف الإعدادات معًا.

```js
window.RAQEEM_GALLERY = {
  annual: {
    src: "assets/gallery/annual-gathering.jpg",
    alt: "المشاركون في تجمع رقيم السنوي"
  },
  photo1: {
    src: "assets/gallery/activity-1.jpg",
    alt: "نشاط تعليمي من مبادرة رقيم"
  },
  photo2: {
    src: "assets/gallery/activity-2.jpg",
    alt: "فريق ومتطوعو مبادرة رقيم"
  },
  photo3: {
    src: "assets/gallery/activity-3.jpg",
    alt: "نشاط مجتمعي من مبادرة رقيم"
  }
};
```

الصورة السنوية تُعرض كاملة دون قص أطرافها. الصور الثلاث الأصغر تملأ إطارًا بنسبة 4:3. تبقى مساحة الصورة ظاهرة إذا كان المسار غير صحيح. تُحمّل الصور عند اقترابها من الشاشة، مع حجز مساحة ثابتة تمنع قفز المحتوى أثناء التحميل. على الهاتف تصبح الخانات عمودًا واحدًا.

**تحسينات المنصة**

- توحيد المنصة داخل الموقع وملف `platform.html` على التصميم والوظائف نفسها.
- عرض شبكة أو قائمة مع حفظ التفضيل على الجهاز.
- ترتيب حسب الأحدث أو الأقدم أو العنوان.
- بحث عربي يتجاهل التشكيل والتطويل واختلافات الألف، مع تصنيفات ومسح للبحث.
- تكبير العناوين والنصوص والأزرار، وتحسين توزيع البطاقات للشاشات الصغيرة.
- تمييز حالات التحميل، وعدم وجود محتوى، وفشل الاتصال، وتعذّر تحميل قناة واحدة، والرجوع إلى نسخة محفوظة.
- زر لتحديث المحتوى، وزر لفتح الفيديو في YouTube.
- إدارة التركيز داخل القائمة والمشغل، وإغلاقهما بمفتاح Escape، ومنع الوصول إلى عناصرهما عند إخفائهما.
- الأرقام ثابتة وواضحة، وعدد الفيديوهات يعكس النتائج المتاحة بالفعل.

المنصة تقرأ أحدث الفيديوهات التي تتيحها خلاصات القناتين؛ هذا لا يضمن إظهار الأرشيف الكامل للقنوات. خدمات YouTube وRSS والخطوط تحتاج اتصالًا بالإنترنت.

**الحركات التي بقيت عمدًا**

- ظهور عنوان البداية مرة واحدة خلال 400ms: تعريف بصري خفيف للموقع.
- دخول قائمة الهاتف من اليمين خلال 240ms: يوضح موضعها، دون تحريك كل رابط على حدة.
- ظهور المشغّل خلال 200ms واختفاؤه خلال 160ms: يوضح فتح نافذة المشاهدة وإغلاقها.
- تغيّر ألوان الأزرار خلال 120ms: استجابة للتفاعل دون تحريك النصوص أو تغيير الأبعاد.
- مؤشر تحميل أثناء انتظار البيانات فقط: يوضح أن جلب المحتوى جارٍ.

فتح القائمة والمشغّل بالكيبورد فوري. عند تفعيل «تقليل الحركة» تتوقف الحركة المكانية والظهور الافتتاحي والدوران، مع إبقاء تدرج خفيف للشفافية. يتوقف فيديو الخلفية أيضًا إذا تغيّر هذا التفضيل أثناء التشغيل.

حُذفت تعريفات الحركات غير المستخدمة ومستمعات المؤشر ومؤقتات الانتقال. بقي تعريف دوران مؤشر التحميل لأنه ما زال مستخدمًا. لا توجد مكتبات حركة مضافة أو محذوفة.

**التحقق المنفذ وحدوده**

نجح فحص صياغة JavaScript وبنية صفحات HTML وعدم تكرار المعرّفات وتوفر ملفات التنسيق والبرمجة المحلية. جرى التحقق من الأرقام والبريد وعدد خانات الصور.

اجتازت الوظائف 11 مجموعة فحوصات في محاكاة DOM، منها التنقل المتكرر، فتح المنصة مباشرة، البحث العربي والترتيب وطريقتا العرض، التركيز في النوافذ، إعداد رسالة الانضمام، الصور وحالات تعذّر تحميل المحتوى. استُخدمت بيانات تجريبية ولم تُرسل نماذج أو رسائل حقيقية.

تعذّرت المعاينة المرئية في متصفح هذه البيئة. لذلك لم تُتحقق بصريًا أحجام الهاتف والكمبيوتر أو سلاسة الحركة على جهاز فعلي، ولم يُختبر الاتصال الحي بقنوات YouTube. يُنصح بمراجعة العرض بعد إضافة الصور على الهاتف والكمبيوتر.
